#### 题目描述如下：

给你一个长度为 `n` 下标从 **0** 开始的字符串 `blocks` ，`blocks[i]` 要么是 `'W'` 要么是 `'B'` ，表示第 `i` 块的颜色。字符 `'W'` 和 `'B'` 分别表示白色和黑色。

给你一个整数 `k` ，表示想要 **连续** 黑色块的数目。

每一次操作中，你可以选择一个白色块将它 **涂成** 黑色块。

请你返回至少出现 **一次** 连续 `k` 个黑色块的 **最少** 操作次数。

**示例 1：**

```
输入：blocks = "WBBWWBBWBW", k = 7
输出：3
解释：
一种得到 7 个连续黑色块的方法是把第 0 ，3 和 4 个块涂成黑色。
得到 blocks = "BBBBBBBWBW" 。
可以证明无法用少于 3 次操作得到 7 个连续的黑块。
所以我们返回 3 。
```

**示例 2：**

```
输入：blocks = "WBWBBBW", k = 2
输出：0
解释：
不需要任何操作，因为已经有 2 个连续的黑块。
所以我们返回 0 。
```

 **提示：**

- `n == blocks.length`
- `1 <= n <= 100`
- `blocks[i]` 要么是 `'W'` ，要么是 `'B'` 。
- `1 <= k <= n`



**看到题目特征，触发对应算法模板**：

**连续**

**长度为 `k`**

要求某个连续区间里的**最小 / 最大 / 数量 / 和**

相邻两个候选区间之间只有少量元素发生变化



看到“至少出现一次连续 `k` 个黑色块”自动转换成“所有长度为k的连续子串“

假设：

```python
blocks = WBBWWBBWBW
k = 7
```

当窗口移动的时候，只有左右两边需要考虑



## 窗口移动的时候怎么更新

这是滑动窗口最关键的地方。

假设当前：

```
[ W B B W W B B ] W
  ↑             ↑
 left          right
```

当前 `W` 数量：

```
white_count = 3
```

窗口向右移动：

```
W [ B B W W B B W ]
    ↑             ↑
```

发生两件事情：

### 新字符进入窗口

如果新进入的是：

```
blocks[right] == "W"
```

那么：

```
white_count += 1
```

### 老字符离开窗口

如果离开的是：

```
blocks[right - k] == "W"
```

那么：

```
white_count -= 1
```

所以代码可以写成如下：

```python
class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:
        ans = cnt_w = blocks[:k].count('W')
        for right in range(k, len(blocks)):
            if blocks[right] == 'W':
                cnt_w += 1
            
            if blocks[right - k] == "W":
                cnt_w -= 1

            # 更新最小值
            ans = min(ans, cnt_w)

        return ans
            
```
