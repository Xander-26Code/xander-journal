# 并发与并行

**并发 Concurrency**：多个任务在一段时间内交替推进。

**并行 Parallelism**是多个任务真的同时执行。



这里的重点在于并发是多个任务在一个时间段内交替运行，从而伪造出来一种“并行”的感觉，但它不是真正的并行。

而并行则是真的多个任务同时执行


## 线程 Thread

线程可以理解成：

> 进程里面真正负责执行代码的工作单元。
> 
> 

一个进程里面可以有多个线程。

比如：

```Plain Text
Python进程
│
├── 线程1
├── 线程2
└── 线程3
```

最普通的 Python 程序其实也至少有一个线程：

```Plain Text
主线程
Main Thread
```

例如：

```Plain Text
print("A")print("B")print("C")
```

默认就是主线程依次执行：

```Plain Text
A
↓
B
↓
C
```

## 进程和线程到底什么关系？

可以这样理解：

```Plain Text
进程 = 公司

线程 = 公司里的员工
```

比如：

```Plain Text
公司 A
├── 员工 1
├── 员工 2
└── 员工 3
```

员工们属于同一家公司，所以通常可以共享公司的资源。

对应到程序：

```Plain Text
一个进程
├── Thread 1
├── Thread 2
└── Thread 3
```

这些线程通常可以共享进程里的数据。
