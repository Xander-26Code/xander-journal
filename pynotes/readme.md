## 建议阅读顺序

1. **先理解程序怎样启动。** 阅读「以主程序的形式运行」，分清直接执行和导入，为组织多个 Python 文件、编写测试打基础。
2. **再理解对象怎样保存状态。** 先读「构造函数与初始化」，再读「封装」，把实例属性、方法和对外接口联系起来。
3. **按需学习文本处理。** 「正则表达式」可以独立阅读，适合遇到字符串匹配、提取或格式校验问题时查阅。
4. **用测试验证自己的理解。** 阅读「pytest 入门」，尝试为前面写过的函数补充正常输入和边界情况的测试。
5. **最后进入并发编程。** 先通过「并发与并行」建立整体认识，再用「Python 多线程基础」练习线程的启动、等待与共享数据保护。
