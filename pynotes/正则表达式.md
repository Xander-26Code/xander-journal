# 正则表达式

# 一、什么是正则表达式？

正则表达式，英文叫：

```Plain Text
Regular Expression
```

通常简称：

```Plain Text
Regex
```

它本质上是一套**描述字符串规律的规则**。

比如现在有一段文本：

```Python
text = """
My phone number is 13812345678.
My friend's number is 15987654321.
This one is invalid: 12345.
"""
```

如果让我们找所有手机号，我们当然可以自己写很多 `if` 判断。

但我们真正想表达的是：

> 我要找一个：
> 
> - 第一位是 `1`
> 
> - 第二位是 `3~9`
> 
> - 后面还有 9 个数字
> 
> - 总共 11 位
> 
> 

用正则表达式就可以写成：

```Python
r'1[3-9]\d{9}'
```

所以你可以把正则理解成：

> **用一种特殊的语言描述“我要找什么样的字符串”。**
> 
> 

---

# 二、最重要的思想：正则就是“一个一个位置去描述”

比如：

```Python
r'abc'
```

非常简单，它的意思就是：

```Plain Text
第一个位置：a
第二个位置：b
第三个位置：c
```

所以：

```Python
import re

text = "hello abc world"

result = re.findall(r'abc', text)

print(result)
```

结果：

```Python
['abc']
```

这里根本没有什么复杂的东西。

---

# 五、`\d`：匹配一个数字

这是你已经用过的。

```Python
r'\d'
```

意思是：

> 匹配一个数字字符。
> 
> 

例如：

```Python
text = "abc123"

print(re.findall(r'\d', text))
```

结果：

```Python
['1', '2', '3']
```

注意：

```Python
\d
```

一次只匹配 **一个数字**。

所以：

```Plain Text
abc123
   ↑↑↑
```

实际上是分别匹配：

```Plain Text
1
2
3
```

你可以暂时把：

```Python
\d
```

理解成：

```Python
[0-9]
```

在 Python 默认的 Unicode 模式下，`\d` 的范围实际上还可能包含某些非 ASCII 数字字符，不过初学时先把它理解成“数字”就行。


# 十三、`{n}`：前面的东西重复 n 次

例如：

```Python
\d{3}
```

意思是：

> 一个数字连续出现 3 次。
> 
> 

也就是：

```Plain Text
数字 数字 数字
```

例如：

```Plain Text
123
456
999
001
```

都符合：

```Python
\d{3}
```

所以：

```Python
\d{9}
```

就是：

> 连续 9 个数字。
> 
> 

现在你的手机号：

```Python
1[3-9]\d{9}
```

就可以完整翻译了：

```Plain Text
1
↓
第一位必须是 1

[3-9]
↓
第二位必须是 3 到 9

\d{9}
↓
后面必须再有 9 个数字
```

也就是：

```Plain Text
1位 + 1位 + 9位
= 11位
```

# 十八、`^`：字符串开头

# 二十一、`\b` 到底是什么？

这个确实比 `^ $` 抽象，所以你刚才懵是很正常的。

`\b` 表示：

> **单词边界（word boundary）**
> 
> 

它也不是一个真正的字符。

它表示一个**位置**。

例如：

```Plain Text
I like python very much
       ↑     ↑
```

`python` 两边存在边界。

所以：

```Python
r'\bpython\b'
```

可以理解成：

> 我要独立出现的 `python`。
> 
> 

例如：

```Plain Text
python
```

✅

```Plain Text
I like python.
```

✅

但是：

```Plain Text
python123
```

❌

```Plain Text
mypython
```

❌

因为这时候 `python` 和旁边的“单词字符”黏在一起了。

---

# 二十二、暂时怎么理解 `\b` 最简单？

你现在可以不要研究它的内部原理。

先简单记：

```Python
\bcat\b
```

大概相当于：

> 找独立出现的 `cat`。
> 
> 

例如：

```Plain Text

```

✅

但是：

```Plain Text

```

❌

因为：

```Plain Text

```

这里虽然有 `cat` 这三个字符，但是它只是另一个单词的一部分。

这就是为什么我们使用：

```Python
\bcat\b
```

# 二十八、`re.findall()` 是干什么的？

你目前最熟悉的应该是：

例如：

```Python
import re

text = "I have 10 apples and 20 bananas."
```

结果：

# 二十九、还有几个常用的 `re` 方法

现在不用全部背，但是先建立概念。

### `re.findall()`

寻找所有匹配。

```Python
re.findall(r'\d+', text)
```

返回：

```Python
['10', '20']
```

---

### `re.search()`

寻找第一个匹配。

```Python
re.search(r'\d+', text)
```

找到第一个以后就停。

---

### `re.match()`

尝试从字符串**开头**进行匹配。

例如：

```Python
re.match(r'\d+', "123abc")
```

可以匹配。

但是：

```Python
re.match(r'\d+', "abc123")
```

不行。

---

### `re.fullmatch()`

要求：

> 整个字符串全部符合规则。
> 
> 

这对手机号验证特别方便。

例如：

```Python
phone = "13812345678"

result = re.fullmatch(r'1[3-9]\d{9}', phone)

print(result)
```

如果整个字符串符合手机号规则，就成功。

所以以后你会发现：

```Python
re.fullmatch(r'1[3-9]\d{9}', phone)
```

和我们写：

```Python
re.match(r'^1[3-9]\d{9}$', phone)
```

在这种简单场景下目标很接近。

对于“验证整个字符串”，`fullmatch()` 往往更直观。

# 三十一、重新来看你的手机号

我们现在应该已经可以很自然地读：

```Python
r'1[3-9]\d{9}'
```

不要把它看成：

```Plain Text
一串神秘符号
```

而是一段语言：

```Plain Text
1
↓
第一个字符必须是 1

[3-9]
↓
第二个字符必须是 3~9 中的一个

\d
↓
数字

{9}
↓
前面的数字重复 9 次
```

最终：

```Plain Text
1 + [3-9] + \d{9}

第一位     第二位       后9位
  1       3~9         数字
```

例如：

```Plain Text
13812345678
││└─────────┘
││     9位数字
│└─ 3~9
└── 1
```

所以它匹配。

而：

```Plain Text
23812345678
```

不匹配，因为：

```Plain Text
第一位是2
```

而正则要求：

```Plain Text
第一位必须是1
```

# 三十二、现在你最应该记住的版本

如果你现在要整理笔记，我建议这一部分直接记下来：

```Plain Text
正则表达式 Regex：
用于按照某种“规则”匹配、查找和处理字符串。

常用规则：

\d        一个数字
\D        一个非数字

\w        一个单词字符
\W        一个非单词字符

\s        一个空白字符
\S        一个非空白字符

.         任意一个字符

[abc]     a、b、c中的一个
[a-z]     a到z中的一个
[0-9]     0到9中的一个

*         前面的内容出现0次或更多
+         前面的内容出现1次或更多
?         前面的内容出现0次或1次

{n}       前面的内容正好出现n次
{n,m}     出现n到m次

^         字符串开头
$         字符串结尾
\b        单词边界

|         或
()        分组
```

Python 中：

```Python
import re
```

最常见：

```Python
re.findall(pattern, text)
```

表示：

> 找出 `text` 中所有符合 `pattern` 的内容。
> 
> 

例如：

```Python
re.findall(r'\d+', 'abc123 def456')
```

得到：

```Python
['123', '456']
```
