# 以主程序的形式运行

**每个 Python 模块都有一个内置变量 \_\_****`name`****\_\_**。一个 `.py` 文件通常就可以看作一个模块。

如果我们在导入包的时候不想让这个包中的语句被直接执行，我们就可以在这个包中加入

```Python
if __name__ == "__main__":
```

这样这个包里面的语句就不会在被导入的文件包中生效，不会影响被导入文件包的输出效果



`__name`\_\_ 表示当前模块的名字；当 Python 文件被直接运行时，\_\_`name`\_\_ 的值是 `"main"`，当它被其他文件导入时，\_\_`name`\_\_ 的值通常是模块名。因此可以利用 `if __name__ == "__main__":` 来区分“直接运行”和“被导入”两种情况。
